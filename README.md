# Superhero API

## Описание

Консольное приложение для поиска самого высокого супергероя по заданным критериям (пол и наличие работы) с использованием Superhero API.

## Требования

- Python >= 3.12
- Poetry

## Установка

Склонируйте репозиторий и перейдите в папку проекта.

Установите зависимости:

```bash
poetry install
```

## Запуск приложения

```bash
poetry run python -m superhero_api.main
```

## Запуск тестов

```bash
poetry run pytest -v
```
